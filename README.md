# Test Langage Hackathon

Code review and analysis testing project for the AI Hackathon application.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ 
- npm or yarn
- TypeScript 5+

### Installation

```bash
# Install dependencies
npm install

# Build the project
npm run build

# Run in development mode
npm run dev
```

### Available Commands

```bash
# Build TypeScript files
npm run build

# Start the application
npm start

# Run in development mode with hot reload
npm run dev

# Run tests
npm run test

# Run linter
npm run lint

# Format code
npm run format
```

## 📁 Project Structure

```
src/
├── index.ts           # Main entry point
├── types/             # TypeScript type definitions
├── utils/             # Utility functions
├── services/          # Business logic services
├── middleware/        # Express middleware
└── routes/            # API routes

dist/                  # Compiled JavaScript output
tests/                 # Test files
```

## 🧪 Testing

This project is used to test the code review application's functionality. Each pull request contains test features for analyzing code quality, security, and coverage metrics.

## 📝 Features

- TypeScript strict mode enabled
- ESLint for code quality
- Prettier for code formatting
- Jest for testing
- Express.js server
- Axios for HTTP requests
